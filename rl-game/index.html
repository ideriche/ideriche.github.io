Get out the vote

You are a canvasser with 25 moves before the polls close. Two houses are supporters, one is not. Knocking on a supporter's door turns them out to vote (once each). Play it yourself, then let a Q-learning agent learn it by trial and error.

Use the arrow keys to walk and Space (or K) to knock.

The state is the canvasser's square plus which houses have voted: 25 squares × 4 voting combinations of the two supporters = 100 states (the non-supporter never votes, so that flag is always "no"). With 5 actions, the agent's table has 500 numbers.

2. The reward: points for each move

These are the only signals the agent gets. Change them and retrain to see what it learns. Changing rewards does not erase what the agent already learned. Press Reset agent to start fresh.

What happened on the movePoints

The points add up: a knock that turns out a supporter scores the per-move cost plus the turnout points.

3. The Q-learning agent

The agent keeps a table with one score for every (state, action) pair, starting at 0. Each move it explores at random 20% of the time (ε = 0.2) and otherwise picks its best-scoring action, breaking ties at random. After each move it updates: Q ← Q + 0.2 × (reward + 0.95 × best Q of the next state − Q).
